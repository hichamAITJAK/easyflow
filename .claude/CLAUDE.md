# Rules

- **Check PRD First**: Always check `PRD.md` in the project root before making plans or changes.
- **Communication Style**: Keep all responses very short, brief, direct, and in simple English. No long explanations.
- **shadcn First**: For any UI work, always use shadcn/ui components via the shadcn MCP first. Only write custom/raw markup (divs, native inputs, etc.) when no shadcn component fits the need. Never reinvent something shadcn already provides.
- **Impeccable for UI Quality**: Always use the `impeccable` skill (critique/audit/polish/etc.) when building or improving UI, to keep design quality high.
